Décision requise : le critère dur de la bascule (0 violation) n'est pas tenu. 0 sur les saisons racontées et sur les graines 0 à 5, mais 63 sur toutes les graines (59 petites poussées de douleur de 2 à 3 sur 10, 4 hausses de charge sous douleur au poignet ; 25 saisons). Ce sont des règles de méthode. Deux voies : un lot de méthode Koach (« KM1c4 ») sur la conduite sous douleur, ou un critère dur « 0 sur les graines 0 à 5 » avec les 63 suivies comme indicateur. KB1 attend cette décision.
