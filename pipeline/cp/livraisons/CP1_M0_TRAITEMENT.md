# Manche 0 : traitement des commentaires dans le moteur 0.2.0

Méthode. Pour chaque profil street relu en manche 0, le commentaire est découpé en points numérotés. Les « Problèmes » viennent d'abord, puis les « À changer ». Chaque point est comparé au programme actuel (`street_<profil>.md`, moteur 0.2.0), lu en entier.

États :
- **corrigé** : le programme actuel répond au point. La preuve est donnée.
- **en partie** : une partie est traitée. Ce qui reste est indiqué.
- **non corrigé** : le programme actuel ne répond pas au point.

Abréviations : S = semaine, RIR = répétitions en réserve, lun/mar/mer/jeu/ven/sam/dim = jours.
