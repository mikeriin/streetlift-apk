# Programmes de référence (privés)

Programmes de champions (sets & reps, streetlifting, calisthénie…) transmis par le propriétaire le 02/10/2026 (DECISIONS_CP.md C2).

Règles (PIPELINE_CP.md §2) :
- servent à extraire des principes chiffrés (structure, fréquences, volumes, intensités, progressions, tests, affûtage) et à comparer les programmes générés ;
- ne sont **jamais** recopiés dans un programme généré (indice de Jaccard exercices × schémas < 0,30 par profil type) ;
- ne sont **jamais** publiés : aucun extrait ni nom d'auteur sur la page de suivi, la page de relecture, dans l'application ou dans `packages/` (seulement des mesures agrégées, anonymes) ;
- ne sont jamais déplacés hors de la branche `pipeline`.
