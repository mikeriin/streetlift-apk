# Programmes de référence (privés)

Le dépôt est **public** : les programmes de référence transmis par le propriétaire le 02/10/2026 (programmes payants, protégés par le droit d'auteur) ne sont **pas** dans ce dossier. Ils sont stockés **chiffrés** sur la branche orpheline `cp-references` (`references.tar.gpg`, mode d'emploi dans son `README.md`) ; la clé n'est donnée que dans le message de lancement des lots qui en ont besoin.

Règles (PIPELINE_CP.md §2) :
- servent à extraire des principes chiffrés (structure, fréquences, volumes, intensités, progressions, tests, affûtage) et à comparer les programmes générés ;
- ne sont **jamais** recopiés dans un programme généré (indice de Jaccard exercices × schémas < 0,30 par profil type, calculé dans la session) ;
- ne sont **jamais** publiés ni nommés : aucun extrait, aucun nom d'auteur ou de programme en clair sur une branche, dans une livraison, sur la page de suivi, la page de relecture, dans l'application ou dans `packages/` (seulement des mesures agrégées, anonymes) ;
- tout travail dérivé détaillé (analyses, séances, ancres du panel) est rajouté sur `cp-references` chiffré avec la même clé.
