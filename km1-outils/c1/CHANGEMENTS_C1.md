## A. Courbe charge-répétitions (koach/modele.py, planification.py, seance.py)
- Ancienne famille : g(λ,k,R) = e^k[(1−λ)·C_LIN·(R−1) + λ·C_LOG·ln R], λ borné à [−0,3 ; 1,2], inverse par Newton (12 pas).
- Nouvelle famille (Box-Cox en répétitions) : γ = 1 − λ ; B(R,γ) = (R^γ − 1)/γ = ln R · φ(γ ln R), φ(x) = (e^x − 1)/x (série à 7 termes pour |x| < 0,01) ; g = e^k·G8·B(R,γ)/B(8,γ), G8 = 7·C_LIN = 0,1855 ; toutes les formes se croisent à 8 répétitions ; λ = 0 → C_LIN(R−1) (inchangé), λ = 1 → C_LOG ln R (inchangé), λ < 0 convexe.
- `_dg` = e^k·G8·R^(γ−1)/(ln 8·φ(γ ln 8)), plancher 0,004 gardé ; `_dg_forme` (dérivée par rapport à λ, avec φ' = (e^x(x−1)+1)/x², série pour |x| < 0,01) remplace l'ancienne expression de dλ dans `_lin_force` ; `_reps_de` = inverse en forme fermée : y = x·ln 8·φ(γ ln 8)/(e^k G8), u = γy, R = 200 si u ≤ −1, sinon ln R = ln(1+u)/γ (série en u pour |u| < 0,01), borné à [1 ; 200].
- Bornes de λ : LAM_MIN = −0,8, LAM_MAX = 1,3 (`courbe`, `_projeter`).
- `planification._g/_dg` appellent la même famille (sans plancher pour `_dg`) ; `seance.charge_de_part` utilise `_reps_de` sur la courbe de population.
- A priori : `a_priori.courbe_forme` [0,3 ; 0,3] → [0,2 ; 0,45]. Justification : ajustement de la famille à sept équations publiées normalisées à 1 répétition, de 2 à 20 répétitions (écart max 1,8 % de charge) : Brzycki 1993 λ = −0,30 ; Lander 1985 −0,29 ; O'Conner 1989 0,14 ; Mayhew 1992 0,25 ; Wathen 1994 0,32 ; Epley 1985 0,33 ; Lombardi 1989 1,00 → moyenne 0,21, écart-type 0,42 (script `km1-outils/c1/fam.py`).
